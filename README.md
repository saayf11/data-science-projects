## Projects

### 1. Statistical Analysis of Human Health & Lifestyle Data
**Course:** STAT1379/COMP6179 — Macquarie University | Oct 2024  
**Tools:** R, Quarto, ggplot2

Analysed anthropometric and behavioural data from 1,000 adults (aged 26–45) to investigate three research questions using inferential statistics. Applied linear regression, two-sample t-test, and chi-square test of independence. Found a statistically significant positive relationship between height and weight (p<0.05) and significant gender-based height differences (p<0.05). Produced a fully reproducible academic report using Quarto.

**Type:** Personal Project | 2023  
**Tools:** Python, scikit-learn, pandas, seaborn
